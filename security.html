Reporting a vulnerability

If you think you have found a security problem in SmartSubs Pro (the plugin, its speech engine, the installers or the update mechanism), please write to:

security@smartsubspro.com

Please include the SmartSubs Pro version, your operating system, and the steps to reproduce the problem. Do not publish the details until a fix is available.

What to expect:

  • an acknowledgement within 3 working days;
  • an assessment and, when the report is confirmed, a fix released as an update; we will tell you when it is available;
  • credit in the release notes, if you want it.

Please do not test against other people's computers or accounts, and do not access data that is not yours.

Supported versions

Security fixes are released for the latest version of SmartSubs Pro. The plugin shows an "Update available" notice when a new version is out; please keep it up to date.

Verifying downloads

Official downloads come only from the GitHub releases of AntonioPennino/SmartSubs-Releases or from your Lemon Squeezy order page. Each release zip has a matching .sha256 file you can use to check that the download has not been altered.

Data handled by the plugin

Transcription runs locally. The plugin contacts Lemon Squeezy (license check), smartsubspro.com and GitHub (update check) and, only if you enable it, Google Gemini with your own API key. See EULA.txt and the Privacy Policy on smartsubspro.com.
