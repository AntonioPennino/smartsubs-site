Section 2

Local Data Processing (OpenAI Whisper)

The core processing pipeline of the SmartSubs Pro software executes exclusively on your local computer.

  • Audio/Video Files: Your project media, client work, and recorded audio are processed locally by the OpenAI Whisper model running on your computer's CPU.
  • No Cloud Uploads: No audio or video data is uploaded to the internet, to our servers, or to third-party servers by the Software, unless you enable the optional Gemini feature described in Section 3.
  • Fully Offline: Once installed, the transcription pipeline runs entirely offline. The Software only goes online for the license and update checks described in Section 4.

Section 3

Optional AI Services (Google Gemini API)

The Software offers an optional "Gemini Hook Detection" feature to automatically highlight high-impact words in your timeline by analyzing vocal intonation and emphasis.

  • Multimodal Audio Processing: If (and only if) you enable this feature, the Software exports a temporary, localized .wav audio file of the voice track from your DaVinci Resolve timeline and uploads it directly to Google Gemini APIs. This allows Gemini to analyze actual speech features (pitch variations, volume shifts, syllable elongation, and speed) rather than relying on a simple text-only script scan.
  • Immediate Data Deletion: The temporary audio file is protected under strict try...finally script blocks and is deleted permanently from Google's servers immediately after the emphasis analysis completes. We do not store, access, or log any audio files.
  • API Keys: You must configure the Software with your own Google Gemini API key. We do not collect, store, or have access to your API key.
  • Third-Party Terms: Google processes this audio data as an independent processor. By using this optional feature, you agree to the Google AI Terms of Service and the Google Privacy Policy.

Section 4

Software Network Connections

Apart from the optional Gemini feature (Section 3), the Software connects to the internet only for licensing and update checks. No audio, video, transcripts or project files are included in these connections.

  • License activation and validation (Lemon Squeezy, USA): When you activate, the Software sends your license key and a device label to the Lemon Squeezy License API (api.lemonsqueezy.com). The device label is made of your operating system, your computer's name (hostname) and a 4-character code derived from your network adapter, so you can recognise your activations; if your computer's name contains your own name, you can rename the computer before activating. While you use the Software it re-validates the license online at most once every 12 hours (license key and activation ID) and keeps working offline for up to 14 days between checks. Deactivating a computer sends the license key and activation ID. Lemon Squeezy's handling of this data is described in its Privacy Policy.
  • Local license file: To bind the license to your computer, the Software computes a hardware fingerprint and stores it, together with the license key, activation ID and last validation time, only in a file on your computer. The fingerprint is never transmitted.
  • Update check: Each time the Software's interface opens, and when you press "Check for updates", it downloads a public version file from smartsubspro.com and, if that is unavailable, from GitHub (raw.githubusercontent.com). No license key or personal data is sent; as with any web request, these servers receive your IP address and the Software version.

  • What is shared: your email address, and your name where you provided it. No payment data, no audio, and no video is ever shared with Trustpilot.

Trustpilot acts as an independent Data Controller for the reviews and account data you provide to them. See the Trustpilot Privacy Policy for details.
